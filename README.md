# 💎 VIP Player Intelligence

MVP для тимлида VIP-отдела онлайн-казино. Инструмент разбирает переписки VIP-менеджеров с игроками и каждый день отвечает на вопрос: **кому и что нужно сделать прямо сейчас**.

- **«Что горит».** Очередь игроков по серьёзности проблемы и ценности. У каждого указано, почему он в очереди и что сделать: кто, что, к какому сроку.
- **Разбор диалога с помощью LLM (Claude).** Суть запроса, решён ли он, флаги с дословной цитатой, оценка менеджера по 6 пунктам, обратная связь и черновик ответа на языке игрока.
- **Карточка игрока.** Цифры из CRM, сигналы и переписка со временем ответов.
- **Сводка по менеджерам.** Время ответа, игнор, нарушения, игроки без контакта.

Для кого инструмент, почему выбраны эти функции и как всё устроено: **[ONE_PAGER.md](ONE_PAGER.md)**.

## Быстрый старт

Нужен Python 3.9 или новее.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/streamlit run app.py
```

Интерфейс откроется на http://localhost:8501. Ключ API для этого не нужен: интерфейс читает готовый LLM-разбор из `out/analysis.json`. Если разбора нет, очередь строится только на сигналах из данных.

### Пересчитать LLM-разбор

```bash
sh scripts/set_key.sh
```

Скрипт сохраняет ключ Anthropic API в `.env` со скрытым вводом. Файл `.env` в `.gitignore`. Можно вместо этого задать переменную `ANTHROPIC_API_KEY`.

```bash
.venv/bin/python -m src.llm
```

Разбирает все диалоги в `out/llm/*.json` и `out/analysis.json`. Результаты кэшируются по хэшу входа, поэтому повторный запуск бесплатен, пока не поменялись промпт, данные или модель. Полезные флаги: `--only D010,D003`, `--force`, `--dry-run D010` (показать промпт без вызова API).

```bash
.venv/bin/python -m src.eval
```

Сравнивает разбор с ручной разметкой и пишет отчёт в `out/eval.md`.

## Как устроено

```
data/players.csv + data/dialogs.json
  → src/signals.py   сигналы, посчитанные кодом: время ответа, тренды депозитов, отток, RG-паттерны, неудачные платежи, ДР
  → src/llm.py       Claude (claude-opus-5-5): разбор переписки строго по JSON-схеме; рубрика — src/prompts/system.md
  → src/scoring.py   объединение и приоритет: серьёзность × количество сигналов × ценность игрока
  → app.py           Streamlit-интерфейс
```

**LLM отвечает за смысл, код — за цифры.** Время, суммы и тренды считаются детерминированно. Серьёзность флага назначает код, а не модель, поэтому очередь стабильна. Пороги лежат в `THRESHOLDS` (`src/signals.py`), серьёзность флагов — в `FLAG_SEVERITY` (`src/llm.py`), рубрика — в `src/prompts/system.md`.

## Качество

[golden.json](golden.json) — моя ручная разметка всех 40 диалогов: 27 обязательных флагов, из них 8 критичных (нарушения ответственной игры и комплаенса), плюс допустимые флаги и диапазоны оценок. Главная метрика — полнота по критичным флагам: пропуск нарушения хуже ложной тревоги.

| Метрика | Значение |
|---|---|
| Критичные флаги найдены | _после прогона_ |
| Точность флагов | _после прогона_ |
| Ложные «critical» на некритичных диалогах | _после прогона_ |

Самопроверка скрипта оценки: `python -m src.eval --self-test`.

## Деплой (Streamlit Community Cloud)

1. Закоммитить `out/analysis.json` после прогона `python -m src.llm`.
2. На share.streamlit.io: **Create app** → репозиторий → ветка `main` → файл `app.py`. В **Advanced settings** выбрать Python 3.11.
3. Ключ API на сервере не нужен: приложение только читает готовый разбор.
